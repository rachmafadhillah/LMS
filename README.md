# LMS AkademiKita

Laravel 12 API + React/Vite frontend + PostgreSQL + Sanctum + Spatie Permission.

## Dokumentasi Setup Lengkap

Baca dari awal sampai jalan:

```text
SETUP.md
```

## Setup Cepat

```powershell
.\scripts\setup.bat
.\scripts\run.bat
```

- Frontend: `http://127.0.0.1:5173`
- Backend: `http://127.0.0.1:8000`
- API: `http://127.0.0.1:8000/api`
